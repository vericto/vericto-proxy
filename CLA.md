# Vericto Contributor License Agreements

The current Vericto Individual Contributor License Agreement is:

- **[ICLA version 1.1](legal/cla/1.1.md)**, effective 2026-11-02.

Read that version before contributing. The CLA workflow links directly to its
permanent file and records its version and SHA-256 hash with each signature.

## Version archive

| Version | Effective date | Status | Signature records |
|---|---:|---|---|
| [1.1](legal/cla/1.1.md) | 2026-11-02 | Current | `signatures/v1.1/cla.json` on the `cla-signatures` branch |
| [1.0](legal/cla/1.0.md) | 2026-10-06 | Superseded; no signatures recorded | `signatures/v1.0/cla.json` on the `cla-signatures` branch |

A versioned file under `legal/cla/` is immutable once published. Vericto does
not overwrite it. A substantive change requires a new versioned file, a new
signature-record path and a new signature for future Contributions. A newer
version does not retroactively change the agreement governing an earlier
Contribution.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the signing process and
[CLA_PRIVACY_NOTICE.md](CLA_PRIVACY_NOTICE.md) for the data recorded.
